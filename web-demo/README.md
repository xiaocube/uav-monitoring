# SkyGuard 无人机监测系统 Web Demo

基于 YOLOv11 的无人机目标检测 Web 演示系统，支持实时视频检测和参数调节。

## 功能特性

- 🎥 实时视频检测（支持摄像头）
- 🎛️ 可视化参数调节（置信度、IOU、分辨率、设备）
- 📊 检测结果实时展示（目标数量、坐标、置信度）
- 📝 系统日志实时输出
- 🎨 深色科技风格界面
- 🔌 支持演示模式（无需后端也能体验）

## 快速开始

### 方式一：一键启动（推荐）

```bash
cd web-demo
chmod +x start.sh
./start.sh
```

脚本会自动：
- 激活 Python 虚拟环境
- 安装前端/后端依赖
- 启动后端服务器（端口 5000）
- 启动前端开发服务器（端口 5173）
- 自动打开浏览器

### 方式二：手动启动

#### 1. 启动后端

```bash
cd web-demo/server
python app.py
```

#### 2. 启动前端

```bash
cd web-demo
npm install
npm run dev
```

#### 3. 访问系统

打开浏览器访问：http://localhost:5173

## 配置参数

| 参数 | 说明 | 默认值 | 范围 |
|------|------|--------|------|
| conf | 置信度阈值 | 0.25 | 0.1 - 0.9 |
| iou | IOU 阈值 | 0.45 | 0.1 - 0.9 |
| imgsz | 输入分辨率 | 640 | 320 - 1280 |
| device | 推理设备 | mps | cpu / mps / cuda |

## 技术栈

### 前端
- React 18 + Vite
- TailwindCSS
- WebSocket (Socket.IO)

### 后端
- Python Flask
- Flask-SocketIO
- OpenCV
- Ultralytics (YOLOv11)

## 演示模式

如果后端服务器未启动，系统会自动进入演示模式，使用模拟数据展示界面效果。

## 快捷键

- 点击「开始检测」按钮启动检测
- 点击齿轮图标展开/收起参数设置
- 拖动滑块实时调整参数

## 系统要求

- macOS / Linux / Windows
- Python 3.8+
- Node.js 16+
- 支持的推理设备：
  - CPU（通用）
  - MPS（Apple Silicon）
  - CUDA（NVIDIA GPU）
